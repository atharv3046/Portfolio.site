## 🛠 Installation and Setup Instructions

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- Git

### Getting Started

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/atharv3046/portfolio.git
   cd portfolio
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Run Development Server:**
   ```bash
   npm start
   ```
   The application will open at [http://localhost:3000](http://localhost:3000)

4. **Build for Production:**
   ```bash
   npm run build
   ```

### Project Structure

```
src/
├── components/
│   ├── Home/          # Landing page with introduction
│   ├── About/         # About section with skills & tools
│   ├── Projects/      # Project showcase
│   ├── Resume/        # Resume section
│   ├── Navbar.js      # Navigation component
│   ├── Footer.js      # Footer component
│   └── Particle.js    # Particle effect background
├── Assets/            # Images and media files
├── App.js             # Main application component
└── style.css          # Global styling
```

## 📝 Customization

To personalize this portfolio with your own information:

1. **Update Home Section:** Edit `/src/components/Home/Home.js`
   - Change your name and introduction
   - Update social media links

2. **Update Projects:** Edit `/src/components/Projects/Projects.js`
   - Add or remove projects
   - Update project descriptions and links

3. **Update Skills:** Edit `/src/components/About/Techstack.js` and `/src/components/About/Toolstack.js`
   - Add your technical skills and tools

4. **Update Resume:** Place your resume PDF in the public folder and link it in `/src/components/Resume/ResumeNew.js`

5. **Styling:** Customize colors in `/src/style.css` and component CSS files
